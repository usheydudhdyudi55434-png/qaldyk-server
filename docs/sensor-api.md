# Датчик API және өрт қаупінің белгілері

## Құрылғы дерегін жіберу

```
POST /api/sensor/<container_id>/
Content-Type: application/json
```

| Өріс | Міндетті | Мәні |
|---|---|---|
| `distance` | иә | Датчиктен қоқысқа дейінгі қашықтық, см |
| `fill_level` | иә | Толу деңгейі, 0–100 % |
| `temperature` | жоқ | Контейнер ішіндегі температура, −50…150 °C |
| `gas_level` | жоқ | MQ-2 түтін/газ датчигінің ESP32 ADC мәні, 0–4095 |
| `fire_risk` | жоқ | Құрылғының өз бағасы: `NORMAL`, `WARNING` немесе `DANGER` |
| `latitude`, `longitude` | жоқ | GPS координаталары, екеуі бірге |

Мысал:

```json
{"distance": 149.29, "fill_level": 0.0, "temperature": 5.19, "gas_level": 3628, "fire_risk": "WARNING"}
```

Жауап `201` және сервер есептеген `fire_risk` пен `fire_note`. Жарамсыз мән
болса `400` қайтады және ештеңе сақталмайды. Температура мен газ өрістері жоқ
ескі прошивка бұрынғыдай жұмыс істейді.

## Өрт қаупі қалай бағаланады

Датчиктер өртті **алдын ала болжамайды**. Олар өртпен бірге немесе одан бұрын
жиі кездесетін белгілерді байқайды. Шешімді сервер қабылдайды (`sensor/fire.py`):

| Белгі | Ескерту (WARNING) | Қауіпті (DANGER) |
|---|---|---|
| Температура | ≥ 50 °C | ≥ 65 °C |
| Температураның көтерілу жылдамдығы | ≥ 8 °C/мин (соңғы 10 минуттағы көрсеткішпен салыстырғанда) | — |
| Түтін/газ (MQ-2) | ≥ 3000 (шкаланың ~73 %) | ≥ 3800 (~93 %) |

Қосымша ережелер:

- Екі тәуелсіз ескерту белгісі қатар болса (мысалы, ыстық және түтін), деңгей **қауіпті** болады.
- Құрылғының `fire_risk` мәні деңгейді **көтере** алады, бірақ ешқашан төмендетпейді.
- Шектер нақты өрт сөндіру датчиктерінің принципіне сүйенеді: жылу датчиктері шамамен
  57 °C-та, «rate-of-rise» датчиктері шамамен 8 °C/мин өсуде іске қосылады.
- **MQ-2 калибрлеуді қажет етеді.** ADC мәні датчикке, қоректенуге және ауаға қарай
  өзгереді, сондықтан нақты құрылғыда таза ауадағы мәнін өлшеп, шектерді
  `sensor/fire.py` ішінде түзету керек.

## Диспетчер панелінде

- Беттің жоғарғы жағында қызыл немесе қызғылт сары дабыл жолағы, браузер қойындысының атауы өзгереді.
- «Өрт қаупі» көрсеткіші, «Назар аударыңыз» кезегінде бірінші орында.
- Картада жәшік үстінде жалын белгісі, қауіпті деңгейде импульспен жанады.
- Кестеде «Қауіпсіздік» бағаны және «Өрт қаупі» сүзгісі.
- Графикте «Температура» және «Түтін/газ» метрикалары; температура мен газ бір уақыт
  аралығындағы **ең жоғары** мәнмен көрсетіледі, сондықтан қысқа секіріс жоғалмайды.
- Датчик үнсіз қалса да соңғы қауіп белгісі көрсетіле береді: өрт кезінде датчиктің
  өзі істен шығуы мүмкін.
