# Docker контейнерлерінің ресурстарын мониторингтеу және визуализациялау

Qaldyq жобасының барлық контейнерлерінің CPU, жад, желі және диск
ресурстары жиналады, сақталады, графиктермен көрсетіледі және шектен
асса ескерту береді.

## Архитектура

```
 Docker контейнерлері            жинау            сақтау             визуализация
┌───────────────────────┐    ┌──────────┐    ┌────────────┐    ┌──────────────────────┐
│ qaldyk-django         │    │          │    │            │    │ Дашборд              │
│ qaldyk-postgres       │───►│ cAdvisor │───►│ Prometheus │───►│ Ескерту ережелері    │
│ qaldyk-prometheus     │    │  :8080   │ 5с │   :9090    │    │ Grafana :3000        │
│ qaldyk-grafana        │    │          │    │            │    │                      │
│ qaldyk-cadvisor       │    └──────────┘    └────────────┘    └──────────────────────┘
└───────────────────────┘
```

| Компонент | Нұсқасы | Рөлі |
|---|---|---|
| cAdvisor | v0.57.0 | Әр контейнердің ресурс жұмсауын Docker-ден оқып, `/metrics` арқылы береді |
| Prometheus | v3.15.1 | cAdvisor-ды 5 секунд сайын сұрап, уақыт қатарлары ретінде сақтайды |
| Grafana | 13.3.0 | Prometheus-тағы деректерден дашборд пен ескертулер жасайды |

## Іске қосу

```powershell
docker compose up -d
```

Бәрі автоматты түрде дайын болады: Grafana іске қосылғанда `grafana/provisioning`
бумасынан дерек көзін, дашбордты және ескерту ережелерін өзі жүктейді.
Қолмен ештеңе баптаудың қажеті жоқ.

| Сервис | Мекенжайы |
|---|---|
| Grafana дашборды | http://localhost:3000/d/qaldyq-docker |
| Prometheus | http://localhost:9090 |
| cAdvisor | http://localhost:8080 |

## Дашборд: «Docker контейнерлерінің ресурстары»

Жоғарыдағы **Контейнер** сүзгісі арқылы бір немесе бірнеше контейнерді таңдауға болады.
Дашборд 10 секунд сайын өзі жаңарады.

| Бөлім | Панельдер |
|---|---|
| Жалпы шолу | Жұмыстағы контейнерлер саны, CPU және жад (хосттан %), жалпы жад, желі трафигі, хост жады |
| CPU және жад | Әр контейнердің CPU жүктемесі және жады, уақыт бойынша |
| Желі | Әр контейнердің кіріс және шығыс трафигі |
| Диск | Әр контейнердің дисктен оқуы және дискке жазуы |
| Контейнерлер күйі | Кесте: CPU, жад, хост жадының үлесі, желі және жұмыс уақыты |

### Негізгі PromQL сұраулары

| Көрсеткіш | Сұрау |
|---|---|
| CPU, бір ядроның %-ы | `sum by (name) (rate(container_cpu_usage_seconds_total{name=~".+"}[1m])) * 100` |
| Жад | `sum by (name) (container_memory_working_set_bytes{name=~".+"})` |
| Желі: кіріс | `sum by (name) (rate(container_network_receive_bytes_total{name=~".+"}[1m]))` |
| Диск: жазу | `sum by (name) (rate(container_fs_writes_bytes_total{name=~".+"}[1m]))` |
| Жұмыс уақыты | `time() - container_start_time_seconds{name=~".+"}` |

`rate(...)` санауыштың секундтағы өсу жылдамдығын береді, сондықтан «барлық уақытта
жұмсалған CPU секундтары» «қазіргі жүктемеге» айналады. Жад үшін `working_set`
қолданылады: бұл контейнердің шынымен қолданып жатқан, кэшті қоспағандағы жады.

## Ескертулер

Grafana → **Alerting → Alert rules → Qaldyq** бумасында.

| Ереже | Шарт | Күту уақыты | Деңгейі |
|---|---|---|---|
| Контейнер тоқтады | Жұмыстағы Qaldyq контейнерлері 5-тен аз | 1 минут | critical |
| CPU жүктемесі жоғары | Контейнер бір ядроның 80%-дан көбін жұмсайды | 5 минут | warning |
| Жадты көп жұмсап тұр | Контейнер хост жадының 25%-дан көбін алады | 5 минут | warning |

«Күту уақыты» қысқа секірістерден жалған ескерту шықпауы үшін керек: шарт сонша
уақыт бойы үздіксіз орындалғанда ғана ескерту іске қосылады.

### Тексеру

`docker compose stop django` командасымен бір контейнер тоқтатылды:

| Уақыт | Күйі |
|---|---|
| ~09:51 | `django` тоқтатылды |
| 09:51:30 | Normal → Pending |
| 09:52:30 | Pending → **Firing** |
| 09:55:05 | `docker compose start django` |
| 09:55:30 | Firing → Normal |

## Шектеулер

- **Docker Desktop (Windows):** cAdvisor желі мен диск метрикаларын әр контейнер
  бойынша оқуы үшін `privileged: true` және хосттың түбірлік файлдық жүйесі
  (`/:/rootfs`) қажет. Онсыз бұл метрикалар тек бүкіл хост бойынша шығады.
- **Хабарлама жіберу:** ескертулер Grafana-да көрінеді, бірақ сыртқа (пошта,
  Telegram) жіберілмейді. Ол үшін **Alerting → Contact points** бөлімінде арна қосу керек.
- **Қауіпсіздік:** Grafana, Prometheus және cAdvisor порттары желіге ашық.
  Grafana-ның `admin` құпия сөзін міндетті түрде өзгертіңіз.
